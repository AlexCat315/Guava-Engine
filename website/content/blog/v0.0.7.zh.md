# v0.0.7：角色控制与物理工作流继续前进

Guava Engine v0.0.7 已通过 GitHub Releases 提供 macOS Apple Silicon、Windows x86_64 和 Linux x86_64 构建。这个版本点位于项目从“编辑器基础可运行”走向“可以持续验证玩法循环”的阶段。

## 角色与输入

近期主线加入了角色控制器和输入映射基础，并扩展脚本上下文，使角色命令能在明确的物理阶段提交。对应测试覆盖序列化、墙体碰撞和输入控制行为。

## 物理深度

SceneRuntime 持续补齐刚体、复合碰撞体、扫掠与重叠查询。编辑器侧也在扩大物理组件的可编辑范围，让运行时能力能进入实际创作工作流。

## 下一步

短期目标仍是稳定跨平台构建、角色与物理交互，并把 Intent、Capability、观察总线和确认 UI 连成可验证的 AI 编辑路径。规划中的能力会继续留在路线图，而不会提前包装成已完成特性。
