# v0.0.7: character control and the physics workflow move forward

Guava Engine v0.0.7 ships GitHub Release artifacts for macOS on Apple Silicon, Windows x86_64, and Linux x86_64. The project is moving from a runnable editor foundation toward repeatable gameplay-loop validation.

## Character and input

Recent work adds character-controller and input-mapping foundations. Script context changes let character commands enter explicit physics stages, with tests covering serialization, wall collision, and input behavior.

## Physics depth

SceneRuntime continues to expand rigid bodies, compound colliders, sweep, and overlap queries. Editor support is growing alongside the runtime so these capabilities become part of the authoring workflow.

## What comes next

The near-term focus remains cross-platform stability, character and physics interaction, and a validated AI edit path across Intent, Capability, observation, and confirmation UI. Planned work stays on the roadmap until a tested workflow exists.
