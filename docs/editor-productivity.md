# 编辑器工作流

## 属性与场景设置

多选实体后，Inspector 显示所有实体共有的组件与字段。不同值显示“混合值”；
向量按轴显示混合状态。修改一个轴会保留每个实体的其他轴，批量修改记录为一次撤销。
混合值菜单中的“将主选实体的值应用到全部”可以把所有对象设为当前主选实体的值。
锁定实体或试玩期间不能修改实体属性；提交时会重新检查实体和组件是否仍然存在。

通过 Window → Scene Settings 或命令面板进入场景设置。没有选择实体或场景为空时，
Inspector 直接显示场景设置，包括物理和粒子质量设置。

## 命令与问题定位

按 Ctrl/⌘ + Shift + P 搜索本地命令，按 Ctrl/⌘ + P 快速打开脚本或资源。
搜索前缀 `>` 限定命令，`@` 限定资源。方向键选择，回车执行，Esc 关闭。
本地搜索不需要配置模型；AI 意图位于命令面板的独立页签。

底栏显示脚本编译、资源导入和项目导出状态。点击状态打开问题列表。
问题中的“定位来源”会打开脚本对应行列、选择实体，或定位资源文件；
关闭、折叠或最大化面板时，定位操作会恢复并展开目标面板。
失败信息附有下一步，例如修复脚本后重新编译，或修复缺失文件后重新加载资源。

## 工作区和布局

| 工作区 | 默认工具 |
| --- | --- |
| 游戏引擎 · 关卡编辑 | 场景视口、层级、Inspector、资源浏览器 |
| 游戏引擎 · 脚本开发 | 脚本编辑器、输出、层级、Inspector |
| 3D 影视引擎 · 建模与渲染 | 场景视口、Inspector、渲染管线 |
| 3D 影视引擎 · 动画制作 | 场景视口、Inspector、动画播放器和动画图属性 |

每个工作区和布局预设单独保存停靠位置。Window 菜单提供保存、重置和恢复面板；
面板页签栏提供最大化按钮，最大化后的恢复操作保留原来的停靠结构。
窄窗口自动切换到单面板布局，通过顶部面板选择器访问其他工具，窗口变宽后恢复停靠布局。
影视工作区使用场景编辑与渲染工具；游戏试玩和构建运行命令在游戏工作区使用。

## 游戏试玩

视口顶部区分“场景编辑”和“游戏试玩”。游戏试玩支持适应窗口、720p、1080p、
竖屏和方形画面，并可开关游戏 HUD。固定分辨率以对应比例居中显示。
点击游戏画面获得输入焦点，Esc 释放；切回场景编辑会停止试玩并恢复编辑前的场景。

## 资源工作流

打开资源显示预览；“添加到场景”和拖入视口用于创建实体。
右键菜单提供重命名、移动与查找引用。目标路径相对于项目目录，文件格式保持一致。
移动会更新当前场景、场景撤销历史以及项目内的场景文件、脚本和模型引用；
模型依赖会复制到新目录，原位置的共享依赖保留。

“缺失资源”列出场景和模型缺少的文件。选择同格式替换文件后修复原路径，
模型修复同时处理依赖。目标冲突、缺失依赖或验证失败时会给出问题说明，
失败的文件事务会回滚已完成的修改。
