# 编辑器工作流

编辑器由 GuavaUI 构建，并通过 EditorCore 管理选择、面板、场景适配和编辑历史。

## 打开项目

未指定 `--project-dir` 时，编辑器显示欢迎界面并维护最近项目列表。指定目录后会直接进入该项目的编辑工作区。

## 核心面板

- **Hierarchy**：浏览实体层级并切换选择。
- **Inspector**：编辑变换、网格、材质、灯光、物理、音频、脚本和动画组件。
- **Viewport**：显示场景，处理相机与 Gizmo 交互。
- **Asset Browser**：浏览与导入项目资源。
- **Console**：显示编辑器与运行时消息。
- **Render Pipeline / Developer Tools**：检查离线渲染、帧分析、性能监视器、渲染/粒子诊断与运行时状态。

## 面板交互约定

核心面板共享相同的工具条、搜索、计数徽标和空状态。搜索框可直接清除，并在过滤时显示“可见项 / 总项”反馈。

- **Hierarchy** 支持多选、拖拽重排、全部展开/收起、在根节点或当前实体下创建，以及可循环的上一个/下一个搜索匹配。`Actions` 菜单集中提供重命名、复制、聚焦、选择后代、可见性、锁定、移到根节点和删除；对应键盘工作流为 `F2`、`Cmd/Ctrl+D`、`F`、`V`、`L` 与 `Delete`，`Cmd/Ctrl+A` 会选择当前筛选结果。批量删除、复制和移动都作为单次可撤销事务执行，锁定实体或播放状态不会产生部分修改。
- **Inspector** 可按组件名、属性名或当前值搜索；查询会在切换选择后保留，结果自动展开，清空后恢复用户保存的折叠状态。组件选择器支持搜索和渲染、物理、动画、音频、脚本分类；添加、重置与移除可安全应用到整个多选集合，并作为单次原子、可撤销事务提交。多选、锁定实体和播放状态会明确显示只读原因，不会产生部分修改。
- **Viewport** 支持点选、拖拽框选与修饰键多选；`Q/B/W/E/R` 切换选择、框选、移动、旋转和缩放工具，`F` 将整个选择（包含渲染后代）完整取景。视图立方体可按轴向快速定位；`Alt+左键` 环绕、鼠标中键平移、滚轮缩放、右键自由视角（按住 `W/A/S/D/Q/E` 移动，`Shift` 加速），`Alt+右键` 推拉。工具条集中管理局部/世界坐标、着色/线框、阴影、渲染比例、实时预览、物理调试和播放/暂停/停止。多选变换采用原子策略：含锁定对象时隐藏 Gizmo 并禁止部分修改；播放中不允许编辑。`Escape` 取消当前拖动并回滚未提交变换。
- **Asset Browser** 可按网格/列表查看，按网格资源或纹理过滤，并按名称升序、名称降序或类型排序；搜索会跨目录匹配名称和相对路径，计数按当前目录或筛选范围计算。支持 `Shift` 范围选择、`Cmd/Ctrl` 切换选择、方向键导航、`Cmd/Ctrl+A` 选中当前可见项、`Return` 添加网格、`Escape` 清空选区；选中的多个网格可一次加入场景，自动网格排列并作为一个可撤销操作提交。导入会放入当前目录；网格/列表、类别筛选和排序偏好会在下次启动时恢复。
- **Console** 可组合全文搜索与 Info、Warning、Error 严重度过滤；点击消息可展开完整诊断详情，支持复制所选消息或当前可见结果，并可暂停/恢复跟随最新输出。清空历史与隐藏过滤结果是两个独立操作。
- **Render Pipeline** 提供预览、720p、1080p 快速预设，显示路径采样量与图像缓冲区估算；分辨率与 SPP 组合限制在 6400 万路径采样预算内，防止误触发不可控的长时间离线渲染。渲染期间可取消，完成后可在项目 `.guava/renders` 中定位 EXR 输出。
- **Developer Tools** 将 Profiler、Monitors、Render、Particles、Debugger 和 Trace 收在同一工作台。Debugger 汇总编辑器、帧/渲染、视口和选择状态；内置控制台支持搜索、严重度筛选、最新消息优先和展开详情。Trace 跨帧整合 CPU/GPU 呈现、帧预算、渲染通道、粒子与控制台问题；可暂停或捕获当前窗口，按轨道/严重度/文本筛选并排序，选中事件查看证据、建议和相邻帧上下文，再跳到对应诊断页。
- **Settings** 的 AI 提供方切换会同步切换默认模型并清除未提交的 API 密钥草稿，避免把一个服务商的凭据误存到另一个服务商；移除系统凭据前需要二次确认，错误状态使用明确的错误颜色。

## 播放状态

播放前，编辑器会保留场景快照；暂停会冻结模拟而不丢弃状态；停止会恢复进入播放前的场景。MCP 的 `set_playback_state` 使用相同的 `playing`、`paused` 和 `stopped` 状态。

## 保存与未保存变更

关闭或切换上下文时，编辑器会通过未保存变更对话框保护当前工作。场景导出与保存由 EditorCore 的项目导出和文档层负责。

## 脚本

Inspector 可以直接添加和配置内置脚本。项目级别的稳定脚本 ID、默认参数、热重载与导出规则见[项目脚本](project-scripting.md)。
