# Guava Engine Documentation

Guava Engine is an AI-native 3D game and film engine written in Swift. These pages stay grounded in the repository's package manifests, tests, and build workflow.

## Recommended path

1. [Project overview](project-overview.md)
2. [Installation and quick start](getting-started.md)
3. [Editor workflow](editor-workflow.md)
4. [Architecture](architecture.md) and [module map](module-map.md)
5. [Physics v2](physics-v2.md): fixed-step stages, the wheeled-vehicle API, and current boundaries.

## Project status

The repository includes a working editor, scene and physics runtime, declarative UI, asset workflow, cross-platform release builds, and MCP tools. The deeper semantic pipeline, scene-from-image workflow, and production-depth film renderer remain active development areas.

> A planned capability is a direction, not a claim that it ships today.
