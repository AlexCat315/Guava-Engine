# Roadmap

This roadmap is grounded in current package manifests, tests, release automation, and implementation state. It communicates priorities, not delivery dates.

## Shipped

- Swift package structure for Engine, GuavaUI, Editor, and MCP.
- WebGPU first frame, scene runtime, asset import, and editor viewport.
- GuavaUI composition, themes, text, input, docking, and workspace foundations.
- Hierarchy, inspector, asset browser, console, gizmo, and playback state.
- Release packaging for macOS, Windows, and Linux.

## In progress

- Character control, input mapping, rigid-body behavior, and advanced collision work.
- Cross-platform stability, native builds, and editor distribution.
- End-to-end integration across Intent, Capability, Observation, AI Session, and confirmation UI.
- Usable depth for sequence, path tracing, EXR, and color workflows.

## Planned

- A complete semantic pipeline from structure extraction to semantic memory.
- Reference image to validated SceneDocument drafts.
- Multi-bounce rendering, denoise, Cryptomatte, deep EXR, and render farm depth.
- Cross-process observation and cross-session WorldView reconciliation.

> A capability moves to “Shipped” only when implementation, tests, and a runnable workflow agree.
