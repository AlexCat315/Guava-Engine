# 路线图

路线图以当前包清单、测试、发布流程和实现状态为依据。它表达优先级，不承诺具体发布日期。

## 已完成

- Engine、GuavaUI、Editor 和 MCP 的 Swift 包结构。
- WebGPU 首帧、场景运行时、基础材质、资产导入和编辑器视口。
- GuavaUI 声明式组件、主题、文本、输入、Dock 与工作区基础。
- 层级、检查器、资产浏览器、控制台、Gizmo 和播放状态。
- macOS、Windows 与 Linux 的 Release 打包流程。

## 进行中

- 角色控制器、输入映射、刚体与高级碰撞行为。
- 跨平台稳定性、原生依赖构建和编辑器发行体验。
- Intent、Capability、Observation、AI Session 与确认界面的端到端衔接。
- 序列、路径追踪、EXR 与色彩管线的可用深度。

## 规划中

- 从结构提取到语义记忆的完整语义管线。
- 参考图像到 SceneDocument 的可验证场景草稿。
- 更深的多次反弹、降噪、Cryptomatte、Deep EXR 和渲染农场。
- 跨进程观察总线与跨会话 WorldView 对账。

> 规划项只有在代码、测试和可运行工作流同时落地后才会移动到“已完成”。
