# Guava Engine 文档

Guava Engine 是一个使用 Swift 构建的 AI-Native 3D 游戏与影视引擎。本组文档从可以验证的代码、包清单、测试和构建流程出发，帮助你运行编辑器并理解它的模块边界。

## 建议阅读顺序

1. [项目概览](project-overview.md)：先了解 Engine、GuavaUI、Editor 与 MCP 的职责。
2. [安装与快速开始](getting-started.md)：完成原生依赖和编辑器构建。
3. [编辑器工作流](editor-workflow.md)：打开项目、编辑场景并运行模拟。
4. [架构](architecture.md)与[模块地图](module-map.md)：深入世界模型和 Swift 包结构。

## 当前阶段

Guava 仍处于早期开发阶段。仓库已有可运行编辑器、场景与物理运行时、声明式 UI、资产工作流、跨平台 Release 构建和 MCP 工具；更深的语义管线、图生场景和影视渲染能力仍在持续建设。

> 文档中的“规划中”表示设计方向，不代表当前版本已经实现。
